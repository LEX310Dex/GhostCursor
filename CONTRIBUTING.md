# Contributing to GhostCursor

Thank you for helping test and improve GhostCursor.

## Before opening an issue

Try the latest build from source, confirm that no other process owns the required global hotkeys, and run a test from a separate receiving participant/device.

## Pull requests

Keep changes small and explain how they affect system cursor restoration. Include a recovery plan for new failure modes. Please do not introduce software that silently installs hooks into other apps or bypasses capture security controls.

## Privacy

Do not attach captures containing meeting participants, account details, private documents, or personal identifiers. Screenshots and binaries belong outside the Git repository.
